# Definition

Frame comb state — color, cell size, structural integrity. Drives the frame rotation cadence and detects pesticide/wax accumulation. Comb darkens with each brood cycle as cocoons and propolis build up; cells also shrink slightly each generation. Old dark comb should be rotated out every 3-4 years (12-16 brood cycles).
