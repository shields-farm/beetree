# Description

Silken webbing, tunnels through comb, larvae visible. Comb is being destroyed.

# Action

Remove affected frames immediately. If salvageable, freeze the frame for 48 hours to kill larvae, then clean out webbing. If too far gone, discard.

# Notes

Wax moths attack weak/stressed colonies and stored comb. A strong colony will remove moth larvae themselves — wax moth damage inside a live hive means the colony is too weak to defend. Address the underlying weakness.
