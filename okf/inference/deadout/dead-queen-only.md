# Description

Only the queen is dead, rest of the colony appears normal.

# Diagnosis

Queen died — possible supersedure failure, disease, or accident.

# Notes

Check for queen cells — if present, the colony may requeen itself. If no cells and no eggs, introduce a frame of eggs/young larvae to test if they build emergency cells (confirming queenless). Requeen if you have a mated queen available.
